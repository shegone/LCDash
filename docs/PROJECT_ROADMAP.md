# LCDash Project Roadmap

## Vision
Build a secure web-based operations dashboard for Logan County 911 using the CentralSquare ProSuite APIs.

## Phase 1 - Foundation
- OAuth authentication
- API connectivity
- Token management

## Phase 2 - CAD
- Active Calls
- Call Details
- Units

## Phase 3 - Mapping
- GIS map
- Unit locations

## Phase 4 - Analytics
- Response times
- Supervisor dashboards

## Phase 5 - Integrations
- CommsCoach
- GovWorx
- RapidSOS
- NGA911
- Mindshare
