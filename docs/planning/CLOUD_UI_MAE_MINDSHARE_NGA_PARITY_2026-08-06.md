# Cloud UI parity: MAE, Mindshare/JACK, and NGA simulation

This local-only slice inventories the existing repository surfaces and defines their cloud-safe parity behavior. It does not authorize a provider, ingestion, deployment, permission, or operational integration.

## Route inventory

- MAE: `/mae`, plus reliability and knowledge links. The on-prem experience includes current-operations, analytics, and document inquiries. Cloud MAE is citation-only and remains disabled when the approved advisory source is unavailable.
- Mindshare/JACK: `/mindshare`, `/mindshare/technical`, `/mindshare/library`, `/mindshare/reliability`, `/mindshare/coverage`, `/mindshare/radio`, and the Jack Hines background page. The cloud parity shell preserves navigation and layout, while JACK questions, voice, reliability claims, and coverage claims remain unavailable until reviewed Mindshare documents are ingested.
- NGA simulation: `/nga911` and `/nga911-intelligence`, county, operations, event, and NOVA routes. All displayed records are synthetic. The operations disruption is a visual browser simulation, and event review is a browser-only marker.

## Safety contract

Every interactive surface is advisory, reference, or simulation only. None may dispatch; write to or acknowledge CAD; release alerts; page; activate station or browser tones; transmit radio; route or transfer calls; control ESInet, NGCS, or call-handling positions; or acknowledge operational alarms.

Unavailable sources are shown explicitly. Controls that would ask MAE or JACK are disabled before a status or provider request when their approved source gate is closed. NGA visual simulation uses no notification permission, audio API, provider call, or operational write.

## Mobile parity

Safety and unavailable-state text precedes the primary workspace in document order, remains visible when cards stack, uses the shared command-center styling, and does not depend on hover. Buttons retain their existing touch sizing from the shared command stylesheet.
