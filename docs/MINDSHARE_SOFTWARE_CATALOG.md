## Storage policy

- Index manuals, procedures, application notes, and release notes.
- Catalog software and firmware separately.
- Retain selected install packages only after matching them to deployed
  equipment.
- Record a SHA-256 checksum for every retained software or firmware archive.
- Never place credentials, licenses, tokens, or private keys in the AI index.
