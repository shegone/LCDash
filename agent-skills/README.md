# LCDash local-agent skills

These small, task-specific instructions supplement the root `AGENTS.md`
charter. They make local agents more consistent without changing the project's
hard safety, privacy, or machine-role boundaries.

Read the one skill that matches the assigned work package before acting.
`AGENTS.md` overrides every skill in this folder.

- `lcdash-development` - application code, tests, UI, and development clone.
- `server-227-operations` - read-only diagnostics and approved service work.
- `pc15-avatar-video` - Unreal, iClone, MetaHuman, and rendering work.
- `mae-cad-inquiry` - MAE retrieval, summaries, narratives, and privacy.
- `handoff-documentation` - durable status notes and cross-PC coordination.
