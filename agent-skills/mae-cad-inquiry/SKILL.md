# MAE CAD inquiry skill

Use for MAE call lookups, five-call lists, summaries, detailed reports, and
call narratives.

1. Treat MAE as inquiry-only. Never create, modify, acknowledge, dispatch, or
   release CAD records.
2. Use the requested CFS number or an explicit call-type filter; do not infer
   missing incident facts.
3. Separate observed source fields from a generated narrative or summary.
4. Do not output restricted, unverified, medical, caller, or raw-payload data
   outside the authorized viewer.
5. Make clear that generated text is advisory and never affects dispatch,
   alerting, radio, call routing, or station tones.
