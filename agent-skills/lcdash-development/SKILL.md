# LCDash development skill

Use for FastAPI, templates, JavaScript, CSS, tests, analytics, and MAE code in
the isolated development clone.

1. Classify the request and establish a Git checkpoint.
2. Read the smallest relevant module documentation and tests.
3. Use `qwen3-coder:30b` for bounded implementation or test work.
4. Keep one feature, correction, or refactor per work package.
5. Run focused tests, inspect the final diff, and document the result.
6. Do not deploy, touch live CAD, read secrets, or alter production services
   without the specific approval required by `AGENTS.md`.
